# API Assignment - Postman

This repository contains my submission for the "Exploring and Testing APIs with Postman" assignment.

## API Used
GitHub REST API — GitHub Gists (supports full CRUD: Create, Read, Update, Delete)

Base URL: https://api.github.com

## Files in this repo
- `API_Assignment.postman_collection.json` — Postman collection with all requests and test scripts
- `API_Assignment.postman_environment.json` — Postman environment (base_url, auth_token, gist_id variables)
- `Testing_APIs_with_Postman_Assignment.pdf` — Full report with explanations and screenshots

## How to use
1. Import both JSON files into Postman
2. Set your own GitHub Personal Access Token as the `auth_token` variable
3. Run the requests in order: Authentication → Create → Retrieve → Update → Delete
4. Or use the Collection Runner to run them all automatically
